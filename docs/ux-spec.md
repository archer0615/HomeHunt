# UX Specification

## Navigation

首頁即搜尋頁；入口為搜尋房源、收藏、已看屋、最近降價、設定。

## Search / Filter / Sort

快速篩選：房屋類型、縣市、行政區、捷運站、總價、至少 N 房。更多篩選：單價、室內／權狀坪數、屋齡、樓層、電梯、車位／類型、管理費、建物型態。捷運可選線與多站，不以距離篩選。排序預設最新上架，另有最近更新、總價低／高、單價低／高、室內坪數大到小、最近降價。

## Card / Detail

Card 顯示圖片、標題、總價／單價、房數、室內／權狀坪數、樓層、屋齡、車位、電梯、最近捷運站、來源、首次發現與降價資訊。Null 不顯示為 0；詳情可顯示「資料未提供」。Detail 顯示完整資訊、價格歷史、上架／降價紀錄、收藏／永久排除／已看屋與另開的原始連結。

## Personal State / Offline

收藏與已看屋不需確認；永久排除需確認，立即移出結果並提供 Undo，設定可恢復。狀態存 IndexedDB，不放 URL。PWA 離線可搜尋已下載資料、篩選、排序與管理狀態，顯示資料最後更新與來源成功狀態；空結果提供調整篩選提示。

## URL / Mobile

GitHub Pages 使用 HashRouter；搜尋狀態放 URL，例如 `/#/search?city=...&district=...&minRooms=3`，重開可恢復。手機優先、單手操作；原始來源另開頁面。
