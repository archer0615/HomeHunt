# UX Specification

## Navigation

首頁即搜尋頁；入口為搜尋房源、收藏、已看屋、最近降價、設定。

## Search / Filter / Sort

快速篩選：房屋類型、縣市、行政區、捷運站、總價、至少 N 房。更多篩選：單價、室內／權狀坪數、屋齡、樓層、電梯、車位／類型、管理費、建物型態；有數值範圍的條件可設最低與最高。行政區、捷運站、房屋類型、車位類型及建物型態可多選。捷運可選線與多站，不以距離篩選。排序預設最新上架，另有最近更新、總價低／高、單價低／高、室內坪數大到小、最近降價與符合條件度。排序及篩選條件可由 URL 還原；搜尋條件可在本機儲存為命名預設。

## Card / Detail

Card 顯示圖片、標題、總價／單價、房數、室內／權狀坪數、樓層、屋齡、車位、電梯、最近捷運站、來源、首次發現與降價資訊。Null 不顯示為 0；詳情可顯示「資料未提供」。Detail 顯示完整資訊、價格歷史、上架／降價紀錄、收藏／永久排除／已看屋與另開的原始連結。

## Personal State / Offline

收藏與已看屋不需確認；永久排除需確認，立即移出結果並提供 Undo，設定可恢復。狀態存 IndexedDB，不放 URL；設定可下載及還原本機個人狀態備份。收藏、已看屋及最近降價清單支援搜尋與排序；收藏及已看屋可加上本機文字標籤。PWA 離線可搜尋已下載資料、篩選、排序與管理狀態，顯示資料最後更新與來源最近發布狀態；空結果提供調整篩選提示。

## URL / Mobile

GitHub Pages 使用 HashRouter；搜尋狀態放 URL，例如 `/#/search?city=...&district=...&minRooms=3`，重開可恢復。手機優先、單手操作；原始來源另開頁面。

## 成交參考與房源比較

詳情頁以已發布的 MOI 交易提供同縣市、同行政區、同交易類型、近五年且權狀坪數 ±20% 的參考紀錄，最多顯示十筆；缺少城市、行政區或房屋面積時不提供參考。此篩選代表行政區樣本，不代表地理距離、估價或投資建議。

搜尋結果與詳情頁可將房源加入比較。最多比較四筆，欄位包括地區、類型、總價、單價、權狀／室內坪數、格局、屋齡、樓層、建物型態、電梯、車位及捷運站。比較 ID 存在 URL，方便重開及分享。

## 本機決策與相似物件提示

搜尋排序可選「符合條件度」，按當前已設定的搜尋維度等權計分，並顯示分數依據；未設定條件時維持原排序且不顯示分數。疑似同物件只顯示另一來源房源的人工檢視連結，不合併資料、不阻擋使用者操作。
