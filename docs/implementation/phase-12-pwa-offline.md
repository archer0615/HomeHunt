# Phase 12 — PWA Offline

## Goal

完成 Application Shell 與 Published Data 的離線體驗及更新提示。

## Prerequisites

Phase 11。

## In Scope

Service Worker、shell cache、data cache、offline fallback、known-good dataset、appDataVersion、offline mode、非強制 reload 的 update UX。

## Out of Scope

複雜 Service Worker migration、Push Notification、跨裝置同步。

## Acceptance / Quality Gate

離線可搜尋、filter、sort、favorite、exclude、visited；顯示版本與最後更新；有網路優先新資料；PWA/E2E、typecheck、lint、test、build 通過。
